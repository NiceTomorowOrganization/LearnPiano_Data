# LearnPiano lesson data

Lesson files for the Learn Piano iOS app, served through jsDelivr:

    https://cdn.jsdelivr.net/gh/NiceTomorowOrganization/LearnPiano_Data@main/songs/<id>.mid
    https://cdn.jsdelivr.net/gh/NiceTomorowOrganization/LearnPiano_Data@main/artwork/<id>.jpg

Generated by `Tools/cdn/export_lesson_data.py` in the app repository; edit
the sources there and export again rather than editing these files by hand.

| Path | What |
| --- | --- |
| `catalog.json` | The catalogue (45 songs, 0 hidden). The app reads it from the Firebase Remote Config parameter `lesson_catalog`; this copy is the fallback the app downloads when Remote Config has no value. |
| `songs/<id>.mid` | One lesson per song: the right hand is the track pitched highest on average; marker events (FF 06) mark where "Part by Part" parts start. |
| `artwork/<id>.jpg` | Cover, 420x294 JPEG (shown at 140x98 pt). |

## Catalogue fields

* `baseUrl` — where `midi` and `artwork` paths are resolved. Pin it to a tag
  (`...LearnPiano_Data@v1.0.1/`) for releases: jsDelivr caches branch URLs
  for up to a week, and the app caches each file by its full URL, so a new
  tag is how changed files reach users.
* `songs[].isHidden` / `categories[].isHidden` — `true` leaves the entry out
  of every list in the app without deleting it.
* `songs[].isPremium` (locked: opens with premium or a rewarded ad), `isFeatured`, `difficulty`
  (`easy` / `medium` / `hard`), `categoryIds` — as in the app.
* `midi`, `artwork` — paths under `baseUrl`, or full URLs.
